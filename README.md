# PLP Python Week 3 Assignment

## Files

- `grade_reporter.py`: Calculates learners' grades, counts passes and failures, and calculates the average score.
- `bug_hunt.py`: Fixes three bugs in a Python program that calculates the sum of numbers from 1 to 5.

## Part B Reflection

The hardest bug to find was the incorrect while-loop condition because it did not produce an error message. The program ran successfully but printed the wrong answer because the condition `count < 5` stopped the loop before adding 5. I knew something was wrong when I compared the output with the expected answer of 15.
